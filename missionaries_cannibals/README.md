Missionaries and Cannibals

Move everyone across the river. Cannibals must not outnumber missionaries
on either bank with missionaries. The boat cannot travel empty.
Uses breadth-first search to find the fewest crossings.

Run from the main project folder: python3 missionaries_cannibals/main.py
Enter populations and boat capacity, or press Enter for defaults: 3, 3, 2.
Prints each crossing, both banks, and the boat location.
The default puzzle takes 11 crossings. Reports when no solution exists.

Sudoku Solver

Solve a 9 by 9 grid using backtracking.
Each row, column, and 3 by 3 box must contain digits 1 to 9 without repeats.

Run from the main project folder: python3 sudoku/main.py
Enter nine rows of nine space-separated integers. Use 0 for blanks.
Prints the first solution, or reports invalid input or no solution.
Original clues stay unchanged. Difficult puzzles may take longer.

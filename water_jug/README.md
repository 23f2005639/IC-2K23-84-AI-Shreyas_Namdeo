Water Jug

Measure a target amount in either jug by filling, emptying, or pouring.
Uses breadth-first search to find the fewest moves.

Run from the main project folder: python3 water_jug/main.py
Enter two positive jug capacities and a nonnegative target.
Prints each numbered action, both jug amounts, and the total moves.
Example: capacities 4 and 3, target 2 takes 4 moves.
Reports when no solution exists.
